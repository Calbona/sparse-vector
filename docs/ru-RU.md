# sparse-vector

Разреженный вектор для TypeScript: отображение целых индексов в произвольные значения, в котором хранятся только позиции, отличные от значения по умолчанию

Индексы могут быть отрицательными, и они не обязаны быть последовательными

Поэтому вектор всего с тремя элементами занимает всего три элемента — независимо от того, равны эти три индекса `0, 1, 2` или `-10^9, 0, 10^9`

Эта библиотека намеренно **не** является вектором в математическом смысле

## Установка

```sh
npm install sparse-vector
```

## Использование

```ts
import { SV_vector } from 'sparse-vector';

const vector = new SV_vector(); // значение по умолчанию для пустых позиций: 0 типа number

vector.set(1_000_000, 'далеко');
vector.set(-42, 'отрицательный');

vector.get(1_000_000); // 'далеко'
vector.get(-42);       // 'отрицательный'
vector.get(7);         // 0
vector.size;           // 2
```

Значение по умолчанию можно задать, а позже изменить; любая позиция без явной записи читается как оно

```ts
const counts = new SV_vector<number | null>(null); // пустые позиции — null
counts.set(3, 1);
counts.get(4); // null

counts.defaultValue = 0; // пустые позиции стали 0
```

Тип значений не ограничен — годится что угодно

```ts
const tagged = new SV_vector<unknown>();
tagged.set(0, { kind: 'header' });
```

## API

### `new SV_vector<T>(defaultValue?)`

Создаёт вектор

`defaultValue` — значение по умолчанию для пустых позиций, то есть значение, которое возвращается для любой позиции без явной записи; по умолчанию — `0` типа number

`T` по умолчанию равен `number`

### Свойства

| Член | Описание |
| --- | --- |
| `defaultValue: T` | Читается и записывается; при присваивании немедленно удаляются все записи, строго равные новому значению по умолчанию |
| `size: number` | Количество явно хранимых записей |

### Методы

| Метод | Описание |
| --- | --- |
| `get(index): T` | Значение в `index`; если там нет явной записи, возвращается `defaultValue` |
| `set(index, value): this` | Вставляет или изменяет; допускает цепочку вызовов |
| `has(index): boolean` | Есть ли явная запись в `index` |
| `delete(index): boolean` | Удаляет явную запись там, возвращая значение по умолчанию |
| `clear(): void` | Удаляет все явные записи, возвращая значение по умолчанию |
| `elements(): SV_element<T>[]` | Явные записи в порядке возрастания индекса |
| `keys(): number[]` | Сохранённые индексы, по возрастанию |
| `values(): T[]` | Сохранённые значения в порядке возрастания индекса |
| `clone(): SV_vector<T>` | Независимая копия |
| `[Symbol.iterator]()` | Перебирает явные записи в порядке возрастания индекса |
| `toJSON(): SV_element<T>[]` | То же, что `elements()`, поэтому `JSON.stringify` работает напрямую |

`index` должен быть целым числом — положительным или отрицательным; нецелое число вызывает `TypeError`

Обращение к позиции за пределами данных не вызывает ошибку, а возвращает значение по умолчанию — в этом и смысл этого типа

### `SV_vector.from(elements, defaultValue?)`

Строит вектор из итерируемого объекта с `SV_element`; записи, строго равные значению по умолчанию, отбрасываются; если один индекс встречается несколько раз, побеждает последний

### `SV_element<T>`

```ts
interface SV_element<T = number> {
  index: number;
  value: T;
}
```

Это формат сериализации: обычный объект JSON ровно с двумя ключами `index` и `value`

Обратите внимание: `toJSON()` выводит только сами записи, значение по умолчанию в эту структуру не входит, поэтому при круговом преобразовании JSON его нужно нести с собой

```ts
const json = JSON.stringify(vector);
const restored = SV_vector.from(JSON.parse(json) as SV_element<T>[], vector.defaultValue);
```

## Правила отбрасывания

Запись, равная значению по умолчанию для пустых позиций, никогда не сохраняется

Отбрасывание выполняется по **строгому равенству**, отсюда два следствия:

- `0`, `'0'`, `false` и `null` — четыре разных значения; отбрасывается только полное совпадение по `===`
- `NaN` не строго равен `NaN`, поэтому сохранённый `NaN` остаётся, даже если само значение по умолчанию — `NaN`
