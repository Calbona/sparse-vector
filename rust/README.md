# sparse-vector-rs

**Not yet released.** The Rust implementation of [sparse-vector](https://github.com/Calbona/sparse-vector#readme) is planned for this crate, as `SparseVector` and `Element` — the same semantics the [project README](https://github.com/Calbona/sparse-vector#semantics-shared-by-every-implementation) lays out, with no arithmetic on top

Until it ships, [the TypeScript implementation](https://github.com/Calbona/sparse-vector/tree/main/typescript) is the only one available
